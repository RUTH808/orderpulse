# OrderPulse

E-commerce delivery and customer experience analytics.

## Executed result

Analyzed **99,441 orders** across seven source tables. **6,534 of 96,470 eligible deliveries were late (6.77%)**. See results/metrics.json for all definitions and the source manifest.

## Requirements and installation

- Python **3.12**, Git, and a terminal (Windows PowerShell, macOS, or Linux).
- Internet access for the initial package/data download. No paid API key is required.
- Create and activate a virtual environment in this project folder:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS / Linux:
source .venv/bin/activate
python -m pip install --upgrade pip
```

## What it does

Builds a local DuckDB dimensional warehouse from seven Olist CSV sources. Pre-aggregates items and payments before joining them to orders, preventing one-to-many join inflation. Produces date/customer/product/seller dimensions, order/item/payment facts, monthly KPIs, seller scorecards, state summaries, a searchable browser report, and CSV exports.

A seller enters the review queue only after 30 eligible deliveries. Multi-seller orders count once per seller; seller counts are not additive. Late delivery compares calendar dates, so delivery on the promised day counts as on time. Missing delivery dates are excluded from the denominator. Latest answered review wins if an order has multiple reviews. Dispatch and transit durations exclude impossible negative intervals.

## Run

```bash
pip install -r requirements.txt
# Offline synthetic fixture after dependencies are installed:
python app.py demo --raw data/demo --output results/demo
# Actual Olist data (download once):
python app.py download --raw data/raw
python app.py build --raw data/raw --output results
# View the report (or open results/dashboard.html directly):
python -m http.server 8000 --bind 127.0.0.1 --directory results
```

Open http://localhost:8000/dashboard.html. The report includes a text filter for all tables. Detailed tables are exported to `results/exports/`; `results/warehouse.duckdb` can be queried in DuckDB. The demo and actual data are kept in different folders so rerunning the demo never overwrites the real download. If the automatic Kaggle download is unavailable, download the dataset manually from its source and extract the CSVs into data/raw.

## Business questions and definitions

- Which seller-order groups contribute the most late deliveries? Review the seller scorecard, then compare dispatch and transit durations.
- Which destination states have a high late-delivery share? Use volume and the eligible denominator together.
- Do late deliveries have lower review scores? Treat the comparison as an association, not a causal estimate.
- Merchandise value = item prices, excluding freight. Payments = payment records. Neither is profit or recognized revenue.
- Cancellation rate = canceled orders / all orders. Late rate = late delivered orders / delivered orders with evaluable actual and estimated dates.

See `results/FINDINGS.md`, `warehouse.sql`, and `powerbi/README.md`. Boundary months may be incomplete. The historical dataset is not a claim about present-day Olist operations.
